Instructions

This diagnostic tool helps debug the likes persistence issue:

  1. Check Authentication: Verify you're logged in with a valid JWT token
  2. Toggle Like: Enter an item ID (e.g., rec2s64UUEHkWC6xD) and toggle it. Check Netlify function logs for detailed server-side output.
  3. Fetch Liked Items: Retrieve your current liked items from Airtable to verify persistence

View Server Logs:

  • Netlify Dashboard → Functions → Click on "update-user-prefs" → View Logs
  • Look for logs starting with [func-combo]
